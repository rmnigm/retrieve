# Licences and what is shipped

The rule for every dataset: ship only what the benchmark reads, derived from the source (embeddings, integer
attribute codes, integer interaction sequences, code tables); never re-host a raw source file, and never ship
titles, abstracts, captions, reviews, ratings or user ids. Every part names its source so it can be rebuilt
with the ETL in `evaluation/eval_datasets/etl/` of the code release. The code, the trained encoder
checkpoints and the result records are released under the code release's licence (Apache-2.0).

## Goodreads (`eval-goodreads-work-id/`)

- **Source:** UCSD Book Graph (M. Wan, J. McAuley, *Item Recommendation on Monotonic Behavior Chains*,
  RecSys 2018; M. Wan, R. Misra, N. Nakashole, J. McAuley, *Fine-Grained Spoiler Detection from Large-Scale
  Review Corpora*, ACL 2019), <https://mengtingwan.github.io/data/goodreads>. Its terms: academic use only, cite
  the papers above.
- **Shipped (derived):** the test split as dense integer work ids (`test.parquet`: input history and targets; no user
  id, timestamp, rating, shelf or text), the work-id map, the integer attribute codes (genre, language, format, year
  bucket) with their code tables, the synthetic filter, and the sequential encoder trained on the derived training
  split.
- **Not shipped:** the UCSD files (`goodreads_interactions*`, `goodreads_books*`, `goodreads_book_works*`, the
  genre and author files), the training and validation splits, the edition-to-work map.
- **Rebuild:** `eval-data goodreads download|convert|prep|attrs` from the UCSD mirror. A rebuild is not byte-equal to
  the shipped copy: ties between one user's events at the same second order differently (docs/system/datasets.md
  § goodreads).
- **Use:** for academic research, under the source's terms.

## arXiv (`eval-arxiv-papers/`)

- **Source:** `open-index/open-arxiv` on the Hugging Face Hub (CC0-1.0; arXiv's own metadata is CC0),
  snapshot 2026-03-24. Embeddings by `nomic-ai/nomic-embed-text-v1.5` (Apache-2.0).
- **Shipped (derived):** item and query embeddings of "title. abstract" (d256, d128), arXiv ids, integer attribute
  codes (main category, licence bucket, update-year bucket, version-count bucket) with their code tables, the uniform
  and the cluster-correlated synthetic filters.
- **Not shipped:** titles, abstracts, author names (the source's `papers.parquet`).
- **Licence of the shipped part:** CC0-1.0, as the source metadata. The papers' own licences (recorded per item in
  clause C1) govern their text, which is not shipped.

## PubMed (`eval-pubmed/`)

- **Source:** the MedCPT article embeddings published by NCBI (`ftp.ncbi.nlm.nih.gov/pub/lu/MedCPT/pubmed_embeddings`)
  and the MEDLINE/PubMed baseline (NLM), <https://www.nlm.nih.gov/databases/download/terms_and_conditions.html>.
  Queries by `ncbi/MedCPT-Query-Encoder`. MedCPT and its embeddings are works of the US government (NCBI),
  public domain.
- **Shipped (derived):** a 10 M-article slice of the NCBI embeddings as published, query embeddings of 10,000
  held-out titles, PMIDs, integer attribute codes (MeSH heading, MeSH category, year bucket, journal, has-abstract)
  with their code tables (MeSH headings, journal abbreviations), the uniform synthetic filter.
- **Not shipped:** MEDLINE records, titles, abstracts.
- **Terms:** NLM asks users of MEDLINE/PubMed data to name the source and its version and not to imply NLM's
  endorsement; the embeddings are the NCBI release as served on 2026-09-16, the attributes from the MEDLINE baseline that `eval-data pubmed` downloads (docs/system/datasets.md § pubmed).

## LAION 1M-30M (`eval-laion30m/`)

- **Source:** `laion/relaion2B-en-research-safe` on the Hugging Face Hub (gated; Re-LAION research-safe release),
  parts 0-1. Embeddings of the captions by `nomic-ai/nomic-embed-text-v1.5`.
- **Shipped (derived):** caption embeddings (d256), integer attribute codes (domain, size, similarity, watermark,
  unsafe tags) with the domain code table, held-out caption queries as embeddings, the synthetic filter. No
  caption, URL or image.
- **Terms:** the gated dataset's research-only terms apply to whoever rebuilds it; the derived part is shipped under
  the same research-only condition.

## Synthetic filters

Generated by this code release from a fixed seed (`eval-data synth-filter`, seed 20261008 + draw); no third-party
data beyond the dataset they are drawn over. Same licence as the dataset they belong to.

## Result records (`eval-results/`)

The benchmark's own output (records, per-query sidecars, latency samples): Apache-2.0 with the code release.
